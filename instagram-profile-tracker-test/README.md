# IG Profile Tracker — тестовая версия

Минимальный вариант без Telegram и без хранения списка. Просто выводит
ник посещённого профиля в консоль браузера, чтобы проверить, что
детекция переходов вообще работает.

## Установка

1. `chrome://extensions` → включи «Режим разработчика».
2. «Загрузить распакованное расширение» → выбери папку
   `instagram-profile-tracker-test`.

## Проверка

1. Открой `instagram.com`, залогинься.
2. Открой DevTools (`F12`) → вкладка **Console** (именно на странице
   instagram.com, не в service worker).
3. Переходи по профилям (клик по нику, поиск и т.д.).
4. В консоли при каждом новом профиле должна появляться строка вида:
   `[IG Tracker] Профиль: @username`

Если ники не появляются:
- Проверь, что расширение включено и страница была перезагружена после установки.
- Проверь, что открыт именно `https://www.instagram.com/...` (не `instagram.com` без `www`, если у тебя редирект работает иначе — поправим `matches` в `manifest.json`).
