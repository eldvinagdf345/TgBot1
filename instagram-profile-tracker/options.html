Настройки бота

1. Создай бота через @BotFather в Telegram, скопируй токен.
2. Для отправки себе в личку — напиши своему боту любое сообщение (например /start), затем открой в браузере https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates и найди в ответе "chat":{"id": ...} — это твой Chat ID.
3. Для отправки в канал — добавь бота в канал администратором с правом публикации, а в Chat ID укажи @username_канала (для публичного) или числовой ID канала (для приватного).
