# Instagram Profile Tracker → Telegram

Браузерное расширение (Chrome/Edge, Manifest V3). Пока ты сам вручную ходишь
по Instagram и открываешь профили, расширение запоминает никнеймы
посещённых профилей. Никаких действий за тебя оно не выполняет — не лайкает,
не подписывается, не логинится. Просто читает адрес открытой страницы.

## Как это работает

- Отслеживает переходы на `instagram.com/<username>` (в т.ч. переходы внутри
  SPA, без перезагрузки страницы).
- Отфильтровывает служебные пути (`explore`, `reels`, `direct`, `p` и т.д.),
  оставляя только реальные никнеймы.
- Хранит список локально в браузере (`chrome.storage.local`).
- По кнопке в попапе отправляет накопленный список в твоего Telegram-бота
  через обычный Bot API (`sendMessage`). Есть опция отправлять каждый новый
  ник сразу, без ручной кнопки.

## Установка

1. Открой `chrome://extensions` (или `edge://extensions`).
2. Включи «Режим разработчика» (Developer mode).
3. Нажми «Загрузить распакованное расширение» (Load unpacked).
4. Укажи папку `instagram-profile-tracker`.

## Настройка Telegram-бота

1. В Telegram напиши `@BotFather` → `/newbot`, следуй инструкциям, получи
   **Bot Token** (вид `123456789:AAExAmPle...`).
2. Напиши созданному боту любое сообщение (например `/start`) — иначе бот
   не сможет писать тебе первым.
3. Открой в браузере:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   и найди в JSON-ответе `"chat":{"id": ...}` — это твой **Chat ID**.
4. Открой настройки расширения (иконка расширения → «⚙️ Настройки бота» или
   правый клик по иконке → «Параметры»), вставь Token и Chat ID, сохрани.

## Использование

1. Просто ходи по Instagram в браузере, открывай профили.
2. Открой попап расширения — увидишь список собранных ников.
3. Нажми «Отправить в Telegram» — бот пришлёт тебе список.
4. «Очистить» — стереть накопленный список.

## Приватность

Токен бота и список ников хранятся только локально в браузере
(`chrome.storage.local`). Запросы уходят напрямую с твоей машины на
`api.telegram.org` — сторонних серверов нет.
