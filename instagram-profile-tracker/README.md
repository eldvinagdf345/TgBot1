# Profile Tracker → Telegram

Браузерное расширение (Chrome/Edge, Manifest V3). Пока ты сам вручную ходишь
по Instagram или Threads и открываешь профили, расширение запоминает
никнеймы посещённых профилей. Никаких действий за тебя оно не выполняет —
не лайкает, не подписывается, не логинится. Просто читает адрес открытой
страницы.

## Как это работает

- В попапе расширения есть переключатель **«Старт»**. Пока он выключен —
  переходы никак не отслеживаются, ники не сохраняются.
- Когда переключатель включён — расширение отслеживает переходы на
  `instagram.com/<username>` и `threads.com/@<username>` (в т.ч. переходы
  внутри SPA, без перезагрузки страницы) и отфильтровывает служебные пути
  (`explore`, `reels`, `direct`, `search`, `activity` и т.д.), оставляя
  только реальные никнеймы.
- Собранные ники хранятся локально в браузере (`chrome.storage.local`) и
  никуда не отправляются автоматически. Каждый сохранён с пометкой
  платформы — в списке в попапе видна метка **IG** или **TH**.
- По кнопке **«Отправить в Telegram»** в попапе весь накопленный список разом
  уходит в чат или канал через обычный Bot API (`sendMessage`).
- Галочка **«Отправлять ссылкой»** переключает формат: выключена — уходят
  `@username`, включена — полные ссылки, причём под каждый ник берётся
  ссылка нужной платформы (`https://www.instagram.com/username/` или
  `https://www.threads.com/@username`).
- Кнопка **«Считать выделенное на странице»** — отдельный от автослежения
  способ добавить ников: выдели мышкой кусок страницы (например, список
  «Отметки "Нравится"» или подписчиков) и нажми кнопку. Расширение смотрит
  сначала на ссылки `<a href="/username/">` (Instagram) или
  `<a href="/@username">` (Threads) внутри выделения — то есть реальный
  никнейм, а не отображаемое имя рядом с ним, даже если у профиля вообще
  нет имени. Если ссылок нет (в некоторых списках, например "Отметки
  Нравится", сайт рисует строки без `<a>`), расширение разбирает сами
  текстовые узлы в выделении по двум признакам: 1) строка состоит только из
  латиницы/цифр/точки/подчёркивания без пробелов (в Threads ещё и с
  необязательным "@" впереди) — формат ника; 2) цвет текста в DOM не
  приглушённый (сайт красит отображаемое имя более тусклым/прозрачным
  цветом, чем ник). Второй признак нужен, чтобы короткие имена вроде "DS"
  (которые формально похожи на ник) не попадали в список. Работает
  независимо от тумблера «Старт».
- Горячая клавиша **L**: то же самое, но без похода в попап — выделил
  список на странице, нажал `L`, в правом нижнем углу страницы появится
  всплывающее уведомление с результатом (`✅ Добавлено: N`). Не срабатывает,
  если курсор стоит в поле ввода (например, пишешь комментарий).

## После каждого обновления расширения

Chrome не подгружает новый код content-скрипта в уже открытые вкладки —
только в новые загрузки страницы. После обновления расширения в
`chrome://extensions` обязательно **обнови саму вкладку** instagram.com или
threads.com (F5), иначе кнопка/горячая клавиша будут писать «Открой
страницу instagram.com или threads.com и попробуй снова», хотя всё
настроено верно.

## Установка

1. Открой `chrome://extensions` (или `edge://extensions`).
2. Включи «Режим разработчика» (Developer mode).
3. Нажми «Загрузить распакованное расширение» (Load unpacked).
4. Укажи папку `instagram-profile-tracker`.

## Настройка Telegram-бота

1. В Telegram напиши `@BotFather` → `/newbot`, следуй инструкциям, получи
   **Bot Token** (вид `123456789:AAExAmPle...`).
2. Напиши созданному боту любое сообщение (например `/start`) — иначе бот
   не сможет писать тебе первым.
3. Открой в браузере:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   и найди в JSON-ответе `"chat":{"id": ...}` — это твой **Chat ID**.
4. Открой настройки расширения (иконка расширения → «⚙️ Настройки бота» или
   правый клик по иконке → «Параметры»), вставь Token и Chat ID, сохрани.

## Использование

1. Открой попап расширения и включи переключатель **«Старт»** — без этого
   ничего не записывается.
2. Ходи по Instagram или Threads в браузере, открывай профили.
3. Открой попап расширения — увидишь список собранных ников с пометкой
   платформы (IG / TH).
4. Нажми «Отправить в Telegram» — весь список уйдёт в чат/канал, который
   указан в настройках.
5. «Очистить» — стереть накопленный список.

## Приватность

Токен бота и список ников хранятся только локально в браузере
(`chrome.storage.local`). Запросы уходят напрямую с твоей машины на
`api.telegram.org` — сторонних серверов нет.
