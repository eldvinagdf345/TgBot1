# Instagram Account Switcher

Локальное desktop-приложение (Electron) для быстрого переключения между
несколькими залогиненными Instagram-аккаунтами. Никакой автоматизации,
никакой рассылки, никаких списков "кого фолловить" — только удобная
рабочая область, чтобы отвечать клиентам, которые сами написали первыми,
не перелогиниваясь каждый раз вручную.

## Как это устроено

- Слева — колонка пронумерованных слотов (как на твоём скетче). Клик по
  номеру открывает Instagram именно этого аккаунта в рабочей области справа.
- Каждый слот — отдельная изолированная сессия (свои куки, свой логин),
  как если бы это был отдельный профиль браузера. Логины между слотами не
  пересекаются.
- «+» добавляет новый слот — откроется чистая страница входа в Instagram,
  логинишься вручную один раз, дальше сессия сохраняется между запусками
  приложения.
- Под номером аккаунта — счётчик переходов по ссылкам из пула на этот
  аккаунт (растёт при каждом клике по ссылке в «Пуле клиентов», которая
  открывается именно с него). Цвет меняется по нагрузке: **зелёный** —
  до 5, **оранжевый** — 6-9, **красный** — 10 и больше.
- Двойной клик по слоту — переименовать (например, под название магазина).
- Правый клик по слоту — открывает меню: **Закрепить/Открепить**
  (закреплённые слоты поднимаются в начало списка) и **Удалить** (сессия/
  логин этого слота стирается).
- Кнопка **«📱 Мобильный вид»** в верхней панели — переключает текущий
  открытый аккаунт на мобильный вьюпорт и мобильный User-Agent, как
  «Toggle device toolbar» в DevTools. Настройка запоминается отдельно на
  каждый аккаунт. Полезно для директа — мобильная веб-версия Instagram
  функциональнее десктопной. Ориентация экрана (`screen.orientation`)
  подделывается через DevTools Protocol напрямую, а не только размер
  вьюпорта — иначе Instagram при попытке выложить историю просит
  «повернуть устройство». Дополнительно реально сужается сама область
  рендеринга (не только цифры через CDP), чтобы настоящие пиксели окна
  совпадали с заявленной портретной ориентацией — иначе Instagram иногда
  всё равно замечал несоответствие.
- Стандартное меню Electron (File/Edit/View/Window/Help) отключено —
  никакой функции в этом приложении оно не несёт.
- Кнопка **«🔗»** внизу сайдбара открывает отдельное плавающее окно
  **«Пул клиентов»** (поверх основного окна, можно двигать/держать сбоку).
  Туда добавляются ссылки/ники клиентов, которые уже писали в магазин
  (например, по возврату), с привязкой — какой номер аккаунта уже вёл
  с ними переписку. Клик по ссылке в пуле переключает главное окно на
  этот аккаунт и открывает профиль клиента именно с него — менеджеру
  остаётся один клик на "Написать", чтобы попасть в существующий диалог.
  Если указанный номер аккаунта не подключён — пул покажет
  предупреждение, ничего не переключая. Двойной клик по строке в пуле —
  изменить ссылку/номер, «×» — удалить.
  Прямой ссылки на конкретный тред директа Instagram не даёт технически
  (нет способа получить URL переписки по нику) — открывается профиль,
  дальше один клик до сообщения.
- Номер аккаунта у ссылки **необязателен**. Если не указан — при клике
  ссылка открывается с того аккаунта, что сейчас активен (без
  переключения), бейдж показывает «тек.».
- **«📋 Вставить списком»** — открывает два текстовых поля: ссылки (по
  одной на строку) и номера аккаунтов (по одному на строку, привязка по
  порядку — N-я строка номеров к N-й ссылке). Строка с номерами может
  быть короче списка ссылок или содержать пустые строки — тогда
  соответствующая ссылка остаётся без привязки. Номера нужно вписывать
  самому по своим данным (кто из клиентов с каким аккаунтом уже
  переписывался) — автоматического равномерного распределения по
  аккаунтам нет и не будет: это не тот случай, где угадывание вместо
  знания уместно.

Всё взаимодействие с Instagram (подписки, лайки, ответы в директ) делает
только живой человек внутри открытой страницы — приложение лишь хранит
и переключает сессии, само ничего не кликает и никуда не пишет.

## Установка и запуск

```
cd instagram-account-switcher
npm install
npm start
```

Требуется Node.js (LTS, 18+).

## Хранение данных

Список слотов (номер, название, id сессии) хранится локально в
`accounts.json` в папке данных приложения (`app.getPath("userData")`,
на Windows обычно `%APPDATA%/instagram-account-switcher`). Куки и логины
хранятся Electron'ом отдельно по каждому `partition` — стандартный
механизм изоляции сессий Chromium, ничего никуда не отправляется.
