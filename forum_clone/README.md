# forum_clone

Скрипт создаёт резервную копию вашего Telegram-форума (группы с темами):
создаёт приватную группу-форум с тем же названием, описанием и аватаром,
воссоздаёт все темы (названия + иконки) и копирует в каждую тему всё
содержимое — текст, фото, видео, файлы, голосовые, кружочки, стикеры, GIF,
опросы, контакты, геолокацию — **в том же порядке**, в котором оно было
отправлено в оригинале. Закреплённые сообщения и статус «тема закрыта»
переносятся тоже.

Сообщения не пересылаются с пометкой «Переслано от» — медиа скачивается и
публикуется в клоне как обычное сообщение, поэтому клон выглядит как
самостоятельная копия, а не набор форвардов.

## Тема-навигация

Если в форуме есть тема-оглавление со ссылками на другие темы (по умолчанию
ищется тема с названием **«НАВИГАЦИЯ КАНАЛА»**, задаётся в `.env` через
`NAV_TOPIC_TITLE`), она обрабатывается особым образом:

1. Сначала создаются и полностью заполняются все остальные темы.
2. Только после этого создаётся тема-навигация, и её содержимое копируется
   с одной поправкой: скрытые ссылки (когда текст темы кликабелен, а сама
   ссылка спрятана под ним — именно так обычно оформляют такие оглавления),
   ведущие на темы группы-источника, переписываются на ссылки соответствующих
   тем в новой группе. Остальные ссылки (на внешние ресурсы) не трогаются, и
   ни в одной другой теме ссылки не переписываются — только в этой.

Если в тексте темы-навигации встретится ссылка, вставленная как голый текст
(`t.me/...` виден прямо в сообщении, а не спрятан под кликабельным словом),
скрипт **не** будет её автоматически переписывать (риск случайно испортить
текст), а выведет предупреждение в конце запуска, чтобы вы поправили её
вручную.

## Как это работает

Используется ваш личный Telegram-аккаунт (через Telethon/MTProto), а не бот —
боты не могут создавать группы и не всегда видят полную историю. Скрипт
работает от вашего имени, поэтому клонировать можно только форумы, где вы
состоите и откуда можете читать историю. Новая группа создаётся приватной,
без публичного юзернейма (доступ только по инвайт-ссылке).

## Установка

```bash
cd forum_clone
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

1. `API_ID` / `API_HASH` — получить на https://my.telegram.org (API development tools, бесплатно).
2. `SOURCE_CHAT` — @username форума или его id. Если не знаете id, запустите:
   ```bash
   python -m forum_clone.clone --list-chats
   ```
   и найдите нужный чат в списке (обязательно после первого запуска пройдите вход по номеру телефона — Telethon спросит код из Telegram, при необходимости пароль 2FA).
3. `TARGET_CHAT` — оставьте пустым, чтобы скрипт сам создал новую приватную группу-клон.
   Либо укажите @username/id уже созданной вами пустой группы.
4. `NAV_TOPIC_TITLE` — точное название темы-оглавления, если оно отличается от
   «НАВИГАЦИЯ КАНАЛА». Если такой темы в форуме нет — просто оставьте по
   умолчанию, скрипт её не найдёт и просто пропустит этот шаг.

## Запуск

```bash
python -m forum_clone.clone
```

При первом запуске:
- если `TARGET_CHAT` не указан — создаст новую приватную группу-форум с
  названием, описанием и аватаром источника;
- прочитает список тем источника, создаст такие же темы в клоне (в том числе
  иконки/цвет, где это поддерживает Telegram) — кроме темы-навигации;
- пройдёт по каждой обычной теме от старых сообщений к новым, скопирует их,
  повторит закреп и статус «закрыта»;
- в конце создаст тему-навигацию (если она есть) и скопирует её с
  переписанными ссылками на темы.

Прогресс сохраняется в `state.json`. Если скрипт прервался (обрыв сети,
лимиты Telegram) или вы хотите **повторно запустить его позже, чтобы
докопировать новые материалы** — просто запустите ту же команду ещё раз,
уже скопированные сообщения не задвоятся.

Флаги:
- `--reset` — забыть прогресс и собрать клон заново с нуля.
- `--topics-only` — только создать структуру тем (включая тему-навигацию), без копирования сообщений.
- `--list-chats` — вывести id/username всех ваших диалогов и выйти.

## Несколько резервных клонов

Скрипт рассчитан на один клон за раз. Чтобы держать ещё один запасной клон,
скопируйте папку `forum_clone` (или просто файл `.env`) в отдельную рабочую
директорию со своим `TARGET_CHAT`/`STATE_FILE` и запускайте отдельно.

## Важные ограничения

- **Порядок тем в списке.** Telegram сортирует темы в интерфейсе по
  активности (недавние сообщения — выше), а не по порядку создания, и это
  скрипт переопределить не может. Зато **порядок сообщений внутри каждой
  темы сохраняется точно** — это и было основным требованием.
- **Опросы** пересоздаются как новые (вопрос, варианты, тип — обычный/квиз).
  Голоса и результаты голосования Telegram перенести не позволяет — в клоне
  опрос будет с нулевыми голосами.
- **Стикеры** сохраняют эмодзи, но отвязываются от исходного стикерпака
  (Telegram не даёт сослаться на чужой пак при загрузке нового файла) —
  отображаются как одиночный стикер, не как часть коллекции.
- Часть функций (закрытие темы, закрепление темы в списке, статус «закрытый
  топик») использует менее задокументированные методы Telegram API — если
  конкретная версия Telethon её не поддерживает, скрипт выведет
  предупреждение и продолжит работу, не прерывая копирование.
- Большой форум с большим количеством медиа копируется небыстро — Telegram
  ограничивает скорость (flood-wait), скрипт сам ждёт и продолжает.
  Не уменьшайте `DELAY_SECONDS` слишком сильно — так выше риск временных
  ограничений на аккаунте.
- Используйте это только для материалов, которые вам принадлежат /
  на распространение которых у вас есть права.
- `.env`, `*.session`, `state.json`, `downloads/` содержат приватные данные
  или сессию входа — не публикуйте и не коммитьте их (см. `.gitignore`).

## Дисклеймер по тестированию

Код написан по документированному поведению Telethon/Telegram API, но в
среде, где он собирался, нет доступа к реальному Telegram-аккаунту и к
PyPI, чтобы прогнать его end-to-end. Перед тем как полагаться на клон как на
боевой бэкап, обязательно прогоните скрипт на тестовом форуме с несколькими
темами и разными типами контента (включая опрос, кружочек, стикер и
тему-навигацию) и проверьте результат глазами.
